# 🦁 Daitdanyang Backend (AI RAG Engine)

This is the backend API for the Daitdanyang Pet Shop platform.
It features a high-performance RAG chatbot powered by OpenAI, LanceDB, and Flask.

## 🚀 Deployment Info
- **SDK:** Docker
- **Port:** 7860
- **Base Image:** python:3.10-slim

## 🔑 Required Secrets
- `OPENAI_API_KEY`
- `HF_TOKEN`
- `HF_DATASET_ID`
- `SECRET_KEY`
